## Repository layout

```
codeforces/<contestId>/<index>.cpp     e.g.  codeforces/4/A.cpp
```

| File | Purpose |
|------|---------|
| `sync_cf.py` | Watches Codeforces, commits accepted solutions and refreshes this README |
| `new.py` | Creates a solution file from `template.cpp` (`python new.py 4 A`) |
| `template.cpp` | Starting template for every problem |
| `submissions.json` | Log of accepted submissions (the README table is built from it) |
